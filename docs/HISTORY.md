# 连续精炼床与精炼数据工作台

2026-10-27 合并版。首页 `dist/bed.html` 为电炉—月牙截面连续槽—连铸框架；`dist/laboratory.html` 保留原精炼流程实验室（含混合钢水模型）；`dist/evidence/index.html` 完整保留另一任务的文献数据支持库和下载包；`dist/heating.html` 保留详细热损失工具。

部署方法见 [DEPLOYMENT.md](DEPLOYMENT.md)。直接使用 `dist` 可部署 Cloudflare Pages；Workers 静态托管使用 wrangler.jsonc。`npm test` 运行全部计算检查，`npm run build` 核查静态文件。无需构建依赖。

连续床的设计尺寸、入口成分均是用户设计输入。参考数据明确保留来源工况；未找到连续床实测支持的反应速率、气粉配方及加热效率保持待输入。不能把两种设备的文献参数拼成已验证的连续床工业模型。证据边界见 [BED_EVIDENCE.md](BED_EVIDENCE.md)。

以下为保留的旧功能说明，旧默认参数仍是教学假设，不会自动导入新床模型。

独立HTML/CSS/JavaScript网页，无第三方前端依赖。

## 使用

以静态HTTP服务打开 `dist/laboratory.html`，或访问已发布的私有站点的 laboratory.html 路径。

- 选择Q235、Q355、GCr15、304或316L示例，填写电炉出钢成分和炉容。
- 点击设备库添加工序，拖动或用箭头调整顺序。
- 编辑处理时间、气量、渣料、喷粉和动力学假设。
- 保存对比方案，查看设备加入前后的增量。
- 查看总时间表与物料表，导出JSON方案或CSV物料表。

## 关键边界

所有成分输出为教学估算，不是CFD或FactSage计算。论文数值只作为指定参数的参考，不代表整套流程得到论文验证。VD默认不直接脱硫；启用协同脱硫仍需要前序脱氧及有效渣层。钢与渣中的硫质量在相邻工序间保留。T.O仅为代理指标，不能替代定氧或夹杂物粒径分布。氮暂不计算变化，Ni/Cr/Mo等牌号成分未预测。标准态Nm³与RH原文m³分别计量。

新设备默认插入末期软吹之前。真空工序有效时间与抽空/破空附加时间分开；吹气和喷粉可以与工序重叠，避免重复累计。

## 验证

运行 `node check-model.mjs`，覆盖硫质量守恒、VD默认S不变、VD协同脱硫前提、RH喷粉累计、气体口径分离、负值及无氧/无气边界。

所有资料为公开论文引用，方案仅保存在当前浏览器本机。Sites托管为私有访问。
# 加热与热损失子系统（2026-10-22）

入口：`dist/heating.html`，主工作台导航已加入入口。

- 矩形预热精炼槽，连续活塞流或单批混匀温度近似。
- 计算裸钢辐射/对流、渣层串联导热及表面散热、两层耐材与外表面散热。
- 电磁按铺设米数与kW/m；等离子按数量和单台kW；喷粉以标准反应热、氧量、反应率和热捕集率约束。
- 目标功率与粉耗反算、长度对比、时间/能源/物料总表、实测末温反算效率。
- 默认效率及物性为教学假设；内置2022/2024模拟论文、历史设备参考与NIST原始数据，说明各自边界。
- 达到用户给定液相线或1800°C即停止末温预测。不求解凝固潜热、CFD、电磁场或完整反应网络。

检查：`node check-heat.mjs`（16项热平衡与单位换算检查）；原有`node check-model.mjs`保留。

主工作台新增“温度与元素”标签，也可用 `/#temperature` 直接进入。设备参数区按反应子步骤展示计划温度、元素、范围性质和热力学方向。

## 连续模块滑条修订

- 设备选项直接来自合并数据包 equipment 表；LF、RH、VD 等在连续床中是功能区映射，保留原设备功能、来源和时间口径。
- 框架上可选设备、调整分区长；每段0.5–3m、步长0.5m。这是本网页的设计分配规则，不是文献中的真实钢包/真空罐尺寸。
- 本页全部数字用滑条调整，拖动时实时更新连续通过时间与计算结果。τ=M/ṁ是连续流体通过区段的时间，没有叠加停炉等待。
- 加热区给出加热贡献温差、无加热温差、净温差、出口温度及保温所需输入功率。η不由流量单独推出：η=[ṁcp(Tout实测−Tin实测)+Qloss]/Pin；化学补热以实际反应放热功率为分母。测温反算值不自动覆盖指定效率，超出0–1会标记待核。
- 新增bed-catalog.mjs逐项对应原数据包设备ID，并在计算入口拒绝目录外设备；参考数据仍未经连续床工业标定。

## 并行辅助操作与整床目标规划

主体分区仅按LF/RH/VD等连续功能区串联；补热、扒渣、顶吹/底吹/复吹附着于宿主，不重复增加床长、体积或通过时间。移除宿主会同时移除附着操作，整床重新核算。旧独立辅助段迁移到相邻宿主；冲突操作及旧动力学保留于方案归档，提示用户复核。

速度u=ṁ/(ρA)，单段τ=L/u；吨/小时先转换kg/s。本页的钢水流速不是化学处理能力。bed-planning.mjs按统一目标计算净去除任务、承担区段、缺项和温度缺口；比较0.5倍/当前/1.5倍流量下现有输入的条件结果。局部能力最小值不宣称全床全局最优产能，尤其同一元素存在多个串联区段时。

顶底喷吹分别记气种、标况流率和单耗；N₂活跃但无吸氮模型时N终点未知，改变方向不会自动增加去除率。扒渣记录kg/t及kg/h，不自动产生脱硫收益；分区实际渣覆盖率可覆盖全局值，使热损按实际覆盖面积重新计算，不从扒渣量臆测裸露面积。

同段脱碳和喷粉补热需要独立氧分配及总预算，避免重复用氧。关闭补热后补热输入为0。所有反应/热量仍需要适用的标定参数。整床目标与方案快照只保存在当前浏览器。
